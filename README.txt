PUBLISH ON GITHUB PAGES (FREE)
1. Sign in or create an account at https://github.com
2. Click the + button (top right) > New repository.
3. Repository name: nazim-khairaad-machine
4. Choose Public, then click Create repository.
5. Click Add file > Upload files.
6. Upload index.html from this folder (you can also upload README.txt).
7. Click Commit changes.
8. Open repository Settings > Pages.
9. Under Build and deployment, choose Deploy from a branch.
10. Branch: main; folder: /(root). Click Save.
11. Wait a minute or two, refresh Settings > Pages. GitHub will show your live website link, usually:
    https://YOUR-GITHUB-USERNAME.github.io/nazim-khairaad-machine/
12. Open that link on your phone and laptop to test it.
